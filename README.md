# 🛍️ Customer Shopping Behavior Analysis

An end-to-end data analytics project analyzing **3,900 retail transactions** to uncover insights into customer spending patterns, segmentation, product performance, and subscription behavior — built with **Python, SQL, and Power BI**.

---

## 📌 Overview

This project simulates a real-world data analyst workflow: taking raw transactional data from ingestion through to a stakeholder-ready report. It covers:

- **Data Cleaning & EDA** — Python (pandas)
- **Business Analysis** — SQL (PostgreSQL)
- **Visualization** — Python (matplotlib) & Power BI
- **Reporting** — PDF outcome report with findings and recommendations

**Dataset:** 3,900 rows × 18 columns covering customer demographics, purchase details, and shopping behavior (discounts, subscriptions, ratings, shipping, etc.)

## 🔍 Key Business Questions Answered

The SQL analysis (see [`customer_behavior_sql_queries.sql`](./customer_behavior_sql_queries.sql)) answers 10 questions, including:

1. Revenue generated by male vs. female customers
2. High-spending customers who still used a discount
3. Top 5 products by average review rating
4. Standard vs. Express shipping — average spend comparison
5. Subscriber vs. non-subscriber spend and revenue
6. Products most dependent on discounts
7. Customer segmentation — New, Returning, Loyal
8. Top 3 products per category
9. Repeat buyers and their subscription likelihood
10. Revenue contribution by age group

---

## 📊 Key Findings

| Insight | Detail |
|---|---|
| **Revenue by gender** | Male customers generated **$157,890** vs. **$75,191** from female customers |
| **Subscribers vs. non-subscribers** | Non-subscribers drive **$170,436** in revenue vs. **$62,645** from subscribers |
| **Customer loyalty** | **3,116** customers (80%) are classified as "Loyal" (>10 previous purchases) |
| **Top-rated products** | Gloves (3.86), Sandals (3.84), Boots (3.82) |
| **Discount reliance** | Top discounted items (Hat, Sneakers, Coat) see **~47–50%** of purchases discounted |
| **Revenue by age group** | Young Adults lead at **$62,143**, followed by Middle-aged, Adult, and Senior |

📄 Full findings and business recommendations are in [`Customer_Shopping_Behavior_Analysis_Report.pdf`](./Customer_Shopping_Behavior_Analysis_Report.pdf).

## 🚀 How to Use This Project

1. **Clone the repository**
   ```bash
   git clone https://github.com/<your-username>/customer-shopping-behavior-analysis.git
   cd customer-shopping-behavior-analysis
   ```

2. **Explore the Python notebook**

   Open `Customer_Shopping_Behavior_Analysis.ipynb` to see data loading, cleaning, feature engineering, and matplotlib visualizations.

3. **Load data into your SQL database**

   Follow the notebook's database connection cell (PostgreSQL/MySQL/SQL Server) to load the cleaned dataset, then run the queries in `customer_behavior_sql_queries.sql`.

4. **Open the Power BI dashboard**

   Open `customer_behavior_dashboard.pbix` in Power BI Desktop to explore the interactive dashboard.

5. **Review the reports**

   - `Customer_Shopping_Behavior_Analysis_Report.pdf` — polished findings & recommendations
   - `Customer-Shopping-Behavior-Analysis.pptx` — presentation deck
